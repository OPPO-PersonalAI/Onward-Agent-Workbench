Research / 调研结论

VS Code、JetBrains 和 macOS 设置均采用分类导航与搜索。VS Code 的窄设置编辑器隐藏分类目录；JetBrains 支持直接导出配色文件，并把字体作用域与配色区分。因此采用分类独立页，窄面板折叠导航，主题导出独立于机器设置。

VS Code, JetBrains and macOS use category navigation and search. VS Code hides its table of contents in narrow settings editors. JetBrains supports direct color-scheme export and distinguishes font scopes from colors. Use independent category pages, compact narrow navigation, and theme files separate from machine settings.

Format / 格式Benefit / 优点Trade-off / 取舍
Onward theme JSON / 未采用Precise Onward round-trip / 可精确保留专有外观Onward-specific schema / 专用格式
VS Code color-theme JSON / 用户选定Interoperable workbench/editor/ANSI colors / 跨编辑器复用通用配色字段Onward-specific UI and Classic behavior are approximated / 专有界面与 Classic 行为近似映射

导出当前已保存主题及其修改，不含 Task ID、工作目录、语言、快捷键、字号、系统明暗配对或其他主题。新机器从现有“导入主题”入口读取；导出不依赖原始 JSON/VSIX 文件。未保存草稿先保存或取消，再导出。Onward 画布背景映射至侧栏等通用界面颜色，保留独立编辑器颜色。

Export the current saved theme and its adjustments only: no Task IDs, directories, language, shortcuts, sizes, system pair or other themes. Import it with the existing importer, without original source files. Save or cancel a draft first. Onward canvas colors map to standard surrounding chrome while retaining independent editor colors.
