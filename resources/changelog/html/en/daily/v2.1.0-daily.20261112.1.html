从系统资源管理器 / Finder 直接拖入文件到任意终端分屏

External File & Folder Drag-and-Drop into Terminal Splits

TERMINAL

从 Windows 资源管理器或 macOS Finder 拖拽一个或多个文件/文件夹到任意终端分屏时，目标分屏会即时高亮聚焦，并根据当前 Shell 类型（PowerShell、Cmd、Bash、Zsh）自动完成含空格路径的安全转义与写入。

Drag files or folders from Windows Explorer or macOS Finder straight into any terminal split. The hovered pane highlights with a drop ring, claims focus, and writes shell-escaped paths tailored to PowerShell, Cmd, Bash, or Zsh.

Explorer / Finder Drag Shell-Aware Path Escaping Instant Pane Focus

Windows 后台无感自动更新：零安装向导弹窗、1 秒级重启替换

Windows Seamless Background Auto-Update (Zero Installer Wizard)

UPDATER

告别传统 NSIS 安装器弹窗打断：Windows 更新现已在后台 Worker 线程完成 ZIP 下载、SHA-512 校验与 _update_staged 解压预备，并通过内置签名的无窗口辅助程序 onward-updater.exe 执行原子目录替换——无论点击立即重启更新还是退出应用时静默完成，全程无黑框、无向导打断。

Just like VS Code on Windows, updates now download, verify SHA-512, and extract into _update_staged on a background worker thread, then hand off to the signed console-free onward-updater.exe helper for an atomic directory swap on restart or normal app quit—no NSIS installer wizard required.

Worker ZIP + SHA-512 Signed onward-updater.exe Instant Restart or Swap on Quit
