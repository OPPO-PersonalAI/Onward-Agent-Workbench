浅色终端：文字对比度选择

Light terminal: text contrast decision

Approved: light non-Classic only · 已确认：仅浅色非 Classic

Evidence / 证据

真实开发包截图中，Light Modern 的亮黄色约 2.10:1，亮白色约 2.46:1；Solarized Light 的亮白色与背景相同。当前 xterm 默认值 1 不修正对比度。VS Code 默认值 4.5。

Packaged screenshots show Light Modern bright yellow at about 2.10:1 and bright white at 2.46:1. Solarized Light bright white equals its background. xterm defaults to 1 (no correction); VS Code defaults to 4.5.

Palette → cell colors → contrast check → pixels

建议：浅色非 Classic 主题采用 4.5；主题原始 ANSI 数据不变，只修正显示文字，包含 ANSI256 与 truecolor。Classic 保留 1。

Proposed: use 4.5 for non-Classic light themes. Stored ANSI values stay intact; rendered ANSI256 and truecolor text can also change. Classic stays at 1.

取舍：可读性更好，但部分文字的饱和度/亮度会改变。dim 文字与方框/Powerline 字形有例外，并非所有字符都保证达到 4.5:1。
Trade-off: improved readability can change text saturation/luminance. Dim text and box/Powerline glyphs have exceptions; this does not guarantee 4.5:1 for every glyph.
