# Onward Daily Build v2.1.0-daily.20261117.1

Changes since `v2.1.0-daily.20261102.1`.

## New Features
- Dock the Prompt panel on the left, bottom, or right via Settings → General → Prompt panel position. When docked at the bottom, the panel switches to a three-column layout (History | Editor | Send targets) with resizable columns, and panel sizes are remembered per tab.
- Paste screenshots or copied files into the Prompt editor with Ctrl/Cmd+V to attach them as numbered items (`@1`, `@2`, ...). Each item can be previewed, inserted at the cursor, or removed; removing an item renumbers the rest.
- Type `@` in the Prompt editor to pick an attached item from a popup. When the prompt is sent, each `@k` reference is replaced with the item's file path, and attached items that were not referenced are appended at the end.
- Drop files from Finder or Explorer into the Prompt editor to insert their paths at the cursor.
- Drag files and folders from Finder or Explorer directly into any terminal pane. The target pane is highlighted while hovering, and paths are quoted only when needed for the active shell (Bash / Zsh, PowerShell, or Cmd).
- Redesign Windows auto-update: the update archive is downloaded, checksum-verified, and unpacked in a background worker, then a small windowless helper (`onward-updater.exe`) swaps the install directory either on "Restart to update" or silently when you quit the app. No installer wizard or console window appears, and the swap rolls back automatically if files are locked.
- Show a new "Preparing update" status in Settings while an update is being prepared in the background.
- Open the animated Release Note automatically on the first launch after an upgrade.

## Bug Fixes
- Fix the Ctrl+S / Cmd+S save shortcut in the Prompt editor.
- Pressing Escape while editing a prompt no longer discards the edit.
- In Git Diff, a file you select is no longer deselected when a slow initial load finishes afterwards (most visible on Windows).
- In Git Diff, the scroll position is kept when the diff view is rebuilt or collapsed regions change.
- In Git Diff, the "Jump to Editor" button no longer flickers during background status refreshes.
- Reserve more time for process exit during quit, so the app closes within its time limit more reliably on Windows.
