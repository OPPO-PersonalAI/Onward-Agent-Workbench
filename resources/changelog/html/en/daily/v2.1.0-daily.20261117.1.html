Prompt 面板可停靠在左侧、底部或右侧

Dock the Prompt Panel on the Left, Bottom, or Right

LAYOUT

在 设置 → 常规 → Prompt 面板位置 中选择 左侧（默认）、底部 或 右侧。停靠在底部时，面板会变成横向三栏布局（历史记录 | 编辑器 | 发送目标），栏宽可以拖动调整。每个标签页会分别记住自己的面板尺寸；设置面板始终固定在左侧。

Choose Left (default), Bottom, or Right in Settings → General → Prompt panel position. When docked at the bottom, the panel becomes a three-column layout (History | Editor | Send targets) with draggable column dividers. Panel sizes are remembered per tab, and the Settings panel always stays on the left.

粘贴截图和文件作为附件，用 @1、@2 在 Prompt 中引用

Paste Screenshots & Files as Attachments, Reference Them with @1, @2

PROMPT

在 Prompt 编辑器里按 Ctrl/Cmd+V 粘贴截图或复制的文件，会生成按顺序编号的附件卡片（@1、@2……）。卡片可以预览、在光标处插入引用或移除，移除后其余附件会自动重新编号。输入 @ 会弹出附件列表供选择。发送时，每个 @k 会被替换为对应附件的文件路径（按当前 Shell 需要加引号），没有被引用的附件路径会追加在末尾。另外，把文件从 Finder / 资源管理器拖进 Prompt 编辑器，会在光标处插入文件路径。

Press Ctrl/Cmd+V in the Prompt editor to paste a screenshot or copied files as numbered attachment cards (@1, @2, ...). Each card can be previewed, inserted at the cursor, or removed, and the remaining items are renumbered automatically. Type @ to pick an attachment from a popup. When you send, every @k is replaced with that attachment's file path (quoted for the shell when needed), and attachments you did not reference are appended at the end. Dropping files from Finder or Explorer into the Prompt editor inserts their paths at the cursor.

从 Finder / 资源管理器把文件直接拖进终端

Drag Files and Folders from Finder or Explorer into Any Terminal

TERMINAL

把一个或多个文件、文件夹拖到任意终端窗格上，目标窗格会高亮显示；松开后路径会写入该终端，并且终端获得焦点。路径会按当前 Shell（Bash / Zsh、PowerShell 或 Cmd）的规则处理，只有包含空格或特殊字符时才加引号；多个路径之间用空格分隔，末尾留一个空格，方便继续输入参数。

Drag one or more files or folders onto any terminal pane. The pane under the cursor is highlighted, and on drop the paths are written into that terminal and it takes focus. Paths follow the rules of the active shell (Bash / Zsh, PowerShell, or Cmd) and are quoted only when they contain spaces or special characters. Multiple paths are separated by spaces with a trailing space, so you can keep typing arguments.

Windows 更新改为后台准备，不再弹出安装向导

Windows Updates Are Prepared in the Background, No Installer Wizard

UPDATER

Windows 版的更新包现在会在后台下载并校验，然后在后台线程中解压到暂存目录，此时设置页会显示「正在准备更新」。准备好之后，有两种完成方式：点击 重启并更新 立即替换并重新启动；或者什么都不做，在正常退出应用时静默完成替换。替换由一个不带窗口的小程序 onward-updater.exe 执行，整个过程不会出现安装向导或命令行黑框；如果遇到文件被占用，会自动回滚到旧版本。

On Windows, the update archive is now downloaded and verified in the background, then unpacked into a staging directory on a background thread while Settings shows "Preparing update". Once it is ready, you can either click Restart to update to swap and relaunch right away, or simply keep working and let the swap happen silently when you quit the app. The swap is performed by a small windowless helper, onward-updater.exe, so no installer wizard or console window appears, and it rolls back automatically if any file is locked.
