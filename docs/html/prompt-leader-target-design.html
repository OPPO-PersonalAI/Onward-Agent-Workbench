同类产品依据Peer evidence

最接近的是终端的前缀 / Leader 模式。WezTerm 提供读取 Leader 状态并在右侧状态区显示的官方示例；VS Code 把等待后续键显示在状态栏，并在会话结束时移除。它们让短暂输入模式可感知，同时保留当前工作上下文。小键帽的尺寸、内容及与 Task 编号组合是 Onward 的提案，并非 Apple 或同行的规定。Terminal prefix/Leader modes are the closest peers. WezTerm documents reading Leader state and displaying it in right-side status; VS Code places a pending-chord message in its status bar and clears it when the session ends. These make transient input modes perceptible while preserving context. The keycap dimensions, content and Task-number combination are Onward's proposal, not an Apple or peer requirement.

A · 选定后即收起（推荐）A · collapse on selection (recommended)

Alt ↓: 1 2 3 4→3: [3]→Q: clear

按住选择键显示编号；按下数字就立即只强调选中的 Task，并显示 →3。可以继续按数字改选。尚未选数字时，修饰键按下保留原生事件，由独立菜单抑制避免 Alt 抢焦点，松开即可收起。代价：选定后的其他编号提前消失。Holding shows numbers; the digit immediately leaves only the chosen Task emphasized with →3. Further digits can reselect. Before selection, modifier down retains native delivery with separate menu suppression, allowing release to clear the map. Trade-off: other numbers disappear earlier after selection.
