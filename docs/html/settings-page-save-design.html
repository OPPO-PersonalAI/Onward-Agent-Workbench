一次保存，一个设置子页。

One save. One settings page.

统一草稿、保存与离开确认，让用户清楚知道：哪些修改尚未生效，以及这次 Save 到底保存什么。

Unify drafts, saving and navigation confirmation so users know what is still pending and exactly what Save commits.

2026-10-30 · Onward 2.0.1 · master

01 / 推荐结论

01 / Recommendation

采用「子页级显式保存 + 常驻底部操作栏 + 离页三选项确认」。Use explicit page-level saving, a persistent footer and a three-way unsaved-changes dialog.

以 General、Appearance、Fonts、Shortcuts 为保存单位。Shortcuts 内全部分组共享一个草稿和一次保存，Prompt Input Actions 不再单独提交。About 是信息与操作页，不显示无意义的 Save。

General, Appearance, Fonts and Shortcuts each form one save unit. Every Shortcuts group shares a draft and a single commit; Prompt Input Actions has no independent commit. About contains information and commands, so it has no redundant Save.

收益

Benefits

保存范围可预测；关联快捷键可以一起校验；试改不会影响工作区；离开不会静默丢失草稿。

Predictable scope, combined shortcut validation, safe experimentation and no silent draft loss on navigation.

明确接受的成本

Trade-offs to accept

简单开关也多一次保存；修改后跨页会被打断；外观不再立即改变真实工作区。以一致、可控优先于即时反馈。

Simple toggles need a save, cross-page navigation can be interrupted, and appearance edits no longer immediately change the workspace. Consistency and control take priority over immediate feedback.

05 / 完整交互规则

05 / Interaction contract

场景Situation行为Behavior
修改、改回原值Edit / revert manually比较草稿与最近成功保存的基线；改回相同值自动清除未保存标记。展开、搜索、滚动、选中 Action 不算修改。Compare the draft with the last acknowledged baseline. Returning to equivalent values clears dirty state. Disclosure, search, scrolling and Action selection are not edits.
保存Save保存当前子页所有修改；保留当前页、滚动和选中项。无修改时禁用；存在错误仍可点击以定位问题；录制快捷键期间禁用并解释原因。Save all edits on the current page; keep page, scroll and selection. Disable when clean; permit validation attempts when dirty. Disable during shortcut recording with an explanation.
放弃更改Discard changes恢复当前子页已保存值，留在当前页。不恢复出厂默认，也不关闭设置。用这一明确文案代替含糊的 Cancel；若保留「取消」，语义必须相同且有说明。Restore saved values on this page and stay. This is neither factory reset nor closing Settings. Prefer the explicit label over Cancel; if Cancel is retained, document the same semantics.
切分类、跨页搜索、关闭设置Change category / cross-page search / close干净则直接执行；有修改则先确认，尚不切换页或卸载编辑器。三个选项分别取消导航、丢弃后导航、保存成功后导航。保存失败不离开。Proceed immediately when clean. When dirty, confirm before switching or unmounting. Choices cancel navigation, discard then navigate, or save successfully then navigate. Failure stays put.
同页定位、切 Action／TaskSame-page target / Action / Task不弹离页确认，保留全部草稿。Fonts 中切 Task 不等于切设置子页；保存覆盖本页本次编辑过的所有 Task。No leave prompt; retain all drafts. Selecting a Task in Fonts is not a settings-page transition. Save includes all Tasks edited within that page session.
保存中与失败Saving and failure显示「保存中…」，冻结当前提交快照、防止重复提交；导航等结果，不能再次排队执行多个离开动作。失败保留草稿、显示具体原因并可重试；校验错误展开分组、聚焦首个错误，取消待执行导航。Show Saving…, freeze the submitted snapshot and prevent duplicate commits. Navigation waits; never queue multiple exits. Retain edits on failure with a reason and retry. Validation expands and focuses the first error and cancels pending navigation.
键盘与焦点Keyboard and focus设置获得焦点时 Cmd+S（macOS）／Ctrl+S（Windows/Linux）等于保存；录制器、IME 和上层对话框优先。Esc 先结束录制／子弹层，再走离页确认。对话框锁定焦点，返回后恢复触发位置；不拦截工作区其他编辑器的保存。Cmd+S on macOS / Ctrl+S on Windows and Linux saves when Settings owns focus. Recorders, IME and nested dialogs take precedence. Esc dismisses the inner interaction before requesting exit. Trap dialog focus and restore it on return; do not capture another editor’s Save.
窗口关闭、退出、更新重启Window close / quit / update restart会销毁草稿的正常退出入口同样先确认；仅隐藏窗口且保留草稿时不提示。原生关闭须在主进程销毁窗口前协调。强杀／崩溃不属于能可靠弹确认的路径。Normal exits that destroy drafts share the guard; hiding a window while retaining drafts does not prompt. Coordinate native close before main-process window destruction. Forced termination and crashes cannot reliably show confirmation.

06 / 每个子页保存什么？

06 / What does each page save?

子页Page保存范围与预览规则Commit scope and preview
General语言、诊断、遥测偏好一起进入草稿；保存成功才改变实际行为。语言选择不立刻改变当前界面，避免导航文案在编辑中变化。Language, diagnostics and telemetry preferences enter the page draft and change behavior only after saving. Language selection does not relabel the interface mid-edit.
Appearance主题、系统跟随、定时方案、自定义颜色和导入的主题配置共享草稿。推荐设置内独立预览画布，真实工作区保持当前主题；不再嵌套第二个 Save。导入只是填入草稿；导出明确为「导出已保存主题」，有草稿时要求先保存或放弃。Theme, system mode, schedules, custom colors and imported configuration share one draft. Use an isolated preview canvas while the workspace keeps its current theme; no nested Save. Import populates the draft. Export explicitly targets the saved theme and requires resolving dirty edits first.
Fonts按稳定 Task ID 留住字号、字体及编辑器字号草稿。设置内提供样例预览；「应用到全部」只批量修改草稿，保存才生效，并延续现有全局默认作用域。Task 消失时报告冲突，不默默丢掉修改。Retain terminal/editor font drafts by stable Task ID. Show a local sample. Apply to all edits the draft and takes effect on Save, preserving existing global-default scope. Report removed-Task conflicts rather than silently losing edits.
Shortcuts所有分组＋完整 Prompt Actions 一起保存。冲突校验必须基于整页草稿和实际触发作用域，不能拿旧已保存值误判，也不能一概禁止合法的窗口内复用。旧快捷键在提交前保持有效，预览不能向真实 Task 发送输入。Save every group and complete Prompt Actions configuration together. Validate the combined draft against actual activation scopes, not stale saved values or blanket uniqueness rules. Old bindings remain effective until commit; preview never dispatches to real Tasks.
About版本、检查更新、下载属于信息／命令，不是待保存字段。无 Save/Cancel；重启更新遵守退出确认。导入、导出、重置等上下文命令可留在所属区域；所有持久化提交／放弃按钮统一在底部。Version, update checks and downloads are information/commands, not draft fields. No Save/Cancel; restart respects the exit guard. Contextual import/export/reset commands may remain near their content; commit/discard actions belong in the footer.
外观预览的决策Preview decision

推荐局部样例预览，严格实现「保存才生效」。整应用临时预览更真实，但需要预览回滚、定时主题交互和外部状态协调，也会削弱这条承诺。两者是策略选择，本提案推荐前者，待确认后实施。

Recommend local sample previews to honor “effective only after Save.” Whole-app temporary preview is more realistic but requires rollback, scheduled-theme coordination and external-state handling, and weakens that promise. This proposal recommends local previews, pending approval.

07 / 实现边界与验证计划

07 / Implementation boundary and verification plan

共享控制器，不复制局部 Save

A shared controller

建议 Settings 容器持有页面草稿、baseline、dirty、saving、error 和单个待执行导航；子组件只编辑草稿。共用 Footer 与 Leave Dialog。App 层关闭、切页和原生退出接入同一离开协议。

The Settings host owns page draft, baseline, dirty, saving, error and one pending navigation. Children edit drafts. Share the Footer and Leave Dialog; connect App-level navigation, close and native exit to one protocol.

提交应使用当前页字段补丁＋版本校验，避免旧整份 Settings 快照覆盖面板宽度或其他实时更新。主进程负责持久化和系统快捷键注册；Renderer 只处理轻量草稿、校验与 UI。跨诊断／遥测／快捷键服务的提交和失败回滚需单独设计，不能用多个现有 setter 拼成「伪原子保存」。

Commit a page-scoped patch with revision checks so stale whole-settings snapshots do not overwrite panel width or other live updates. Main owns persistence and system shortcut registration; renderer handles bounded draft logic and UI. Cross-service commit and rollback for diagnostics, telemetry and shortcuts need explicit design, not a sequence of existing setters labeled atomic.

并发修改：未编辑页同步新值；有草稿时只合并未冲突字段，同字段冲突保留草稿并提示解决。面板尺寸、滚动位置属于视图状态，不触发未保存提醒。

External changes refresh clean pages; dirty pages merge only non-conflicting fields, retaining drafts and surfacing same-field conflicts. Panel dimensions and scroll position are view state, not unsaved form edits.

测试必须覆盖两层

Two-layer coverage

单元：dirty 等价比较、页级字段映射、保存／失败／导航状态转换、快捷键整页冲突表、版本冲突与回滚。

Unit: dirty equivalence, page-field mapping, save/failure/navigation transitions, whole-page shortcut conflict matrix, revision conflicts and rollback.

自动化：保存前真实行为不变，保存后生效且重启保留；取消与三种离页选择；所有退出入口；写入／注册失败保留草稿；中英文窄宽布局、键盘与焦点。

Autotest: unchanged runtime before Save, effective settings after Save and restart, discard and all leave choices, every exit path, write/registration failure, bilingual layouts and keyboard/focus.

高频与压力：反复编辑／还原／切页、重复点 Save、延迟确认中退出、25 个 Actions、多个 Task 字体和持续终端输出；异步正确性每例至少 5 次。新增延迟门槛先征求产品预算。

Frequency and stress: edit/revert/navigation loops, repeated Save clicks, exit during delayed acknowledgement, 25 Actions, multi-Task fonts and ongoing terminal output. Repeat asynchronous correctness cases at least five times; agree latency budgets before adding timing gates.

已找到现有相邻测试：run-prompt-input-settings、run-themes-draft、run-themes-visual、run-themes-tasks、run-themes-imports、run-settings-update。实施优先扩展这些 runner，并更新 test/README.md；本轮未编写或执行产品回归。

Adjacent coverage exists in run-prompt-input-settings, run-themes-draft, run-themes-visual, run-themes-tasks, run-themes-imports and run-settings-update. Extend these first and update test/README.md. Product regression tests were not authored or run for this design review.

三平台要求：Windows/Linux 的 Ctrl 与 macOS 的 Cmd、原生退出／窗口隐藏差异、系统快捷键注册失败、字体差异均需覆盖。当前是 Windows 环境中的代码／文档结构分析，未运行任何平台的产品验证。

Cover Ctrl on Windows/Linux versus Cmd on macOS, native quit/hide behavior, system shortcut registration failures and font differences. This review inspected code/documents on Windows; it did not run product validation on any platform.

评审：这是可长期复用的交互模型。Assessment: a reusable long-term interaction model.

真正的改进在于共同的草稿、提交和离开协议。当前技术债是局部保存器、即时 setter 与 App 外部关闭入口分散；只把按钮移动到底部会留下这些问题。下一步应先确认本方案，优先验证整页提交失败时的行为，再统一迁移四个可编辑子页。

The improvement comes from a shared draft, commit and leave protocol. Existing debt is distributed local savers, immediate setters and App-level close paths; moving buttons alone leaves it intact. Confirm the proposal, prove whole-page failure behavior, then migrate all four editable pages consistently.

待确认的推荐组合：子页级保存；底部「放弃更改／保存」且原地保留页面；离页三选项；外观／字体局部预览，保存才改变工作区。

Recommended decision: page-level saving; footer Discard changes / Save while staying on-page; three-way leave confirmation; local appearance/font previews with workspace changes only after Save.
