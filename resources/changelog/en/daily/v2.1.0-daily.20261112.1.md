# Onward Daily Build v2.1.0-daily.20261112.1

Changes since `v2.1.0-daily.20261102.1`.

## New Features
- Support configurable Prompt Panel dock position (left, bottom, right) with a 3-column horizontal bottom layout and per-tab dimension persistence.
- Support file drop path insertion, clipboard image/attachment paste widgets, and @ mention file autocomplete in Prompt Notebook.
- Support dragging external files and folders from the OS file manager directly into terminal panes with automatic shell path escaping.
- Redesign Windows seamless background auto-update with worker-thread zip staging and console-free atomic directory swap via onward-updater.exe.
- Automatically open the interactive bilingual Release Note Showcase on first launch after a version upgrade.
- Fix Ctrl+S save shortcut in Prompt Notebook and do not cancel active prompt edits on Escape.
- Preserve active file selection on delayed Git Diff loads and retain scroll offset across DiffEditor model rebuilds.
- Parallelize unit test runners and fixture builders and canonicalize cross-platform temporary directory paths.

## Bug Fixes
- Prevent delayed initial Git Diff loads on Windows from deselecting a file already clicked by the user.
- Reapply viewport scroll offset after DiffEditorViewModel rebuilds and collapsed-region updates.
- Fix Ctrl+S shortcut handling in PromptEditor and keep edit state intact when pressing Escape.
- Harden Windows ConPTY cwd synchronization and avoid redundant WebContentsView polling before HTML reader ready.
- Stabilize Windows quit-coordinator shutdown sequencing under heavy Git state mirror activity.
- Resolve macOS /var firmlink realpath mismatches and zero-keycode shortcut dispatch edge cases.
