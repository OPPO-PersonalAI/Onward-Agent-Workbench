为什么选 Fluent FlatWhy Fluent Flat

项目Project许可证 / 能力License / capabilities对 Onward 的适配Fit for Onward
Fluent Emoji · FlatMIT · SVG推荐图形库：统一三平台视觉，适合小图标；需独立选择器。Color 全量原始约 131.9MB，Flat 约 17.2MB。Recommended artwork: consistent cross-platform small icons; requires a picker. Full raw Color assets are about 131.9MB versus 17.2MB for Flat.
Frimousse 0.4.0MIT 代码 / MIT Emojibase 数据；React 18/19；虚拟化；中英文搜索。MIT code/data; React 18/19; virtualization; English/Chinese search.适合选择「系统原生 emoji」路线。不是统一 SVG 图集；默认 CDN/localStorage，离线需要本地数据 resolver；Fluent 图片集不是官方即插即用接口。Fits a native-glyph route, not a uniform SVG collection. CDN/localStorage defaults require a local-data resolver for offline use; Fluent artwork is not a documented drop-in set.
Twemoji · maintained fork代码 MIT；图形 CC BY 4.0。MIT code; CC BY 4.0 artwork.图形清晰、Unicode 更新较新；需单独落实图形署名/修改说明，与 MIT 素材的接入条件不同。Clear artwork and newer Unicode coverage, with separate attribution/modification obligations for graphics.
Emoji Mart代码/数据 MIT，内置图片另查许可。MIT code/data; artwork licenses are separate.当前 React 18 可接入；中文 UI 不等于中文搜索，默认词条仍为英文。聊天式完整面板对动作图标选择偏重。Compatible with this app's React 18, but Chinese UI does not supply Chinese search keywords. Its full chat-oriented panel is broader than action-icon selection.

OpenMoji 的素材/元数据为 CC BY-SA 4.0，辅助代码为 LGPL-3.0，不符合本仓库既定依赖约束。中英文搜索可从 MIT Emojibase 构建本地精简索引，同时保留 Unicode/CLDR 上游许可声明。OpenMoji artwork/metadata use CC BY-SA 4.0 and helper code LGPL-3.0, outside this repository's dependency constraints. Bilingual search can use a compact build-time index from MIT Emojibase, retaining upstream Unicode/CLDR notices.

产品依据：Notion 按钮将名称、emoji 与动作一起配置；VS Code 终端配置分别设置 icon 与 color；JetBrains 动作定制支持改图标、排序与恢复默认。这些做法支持「图形承担辨识，颜色作为辅助」的方向。Peer evidence: Notion buttons combine names, emoji and actions; VS Code profiles separate icon and color; JetBrains action customization supports icons, reordering and defaults. These support visual identity complemented by color.
