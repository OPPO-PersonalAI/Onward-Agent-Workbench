Onward Daily Build v2.1.0-daily.20261102.1

Changes since v2.1.0-daily.20260731.1.

New Features

  • Route preview links to matching viewers, the browser panel, and operating-system handlers.
  • Introduce a unified theme system with import/export, system pairing, and per-surface application.
  • Add configurable actions, leader shortcuts, and emoji.
  • Add configurable leader target selection and visual cues, with matching highlights in the left-side Task selector.
  • Organize shortcut groups into collapsible sections.
  • Save Settings drafts per page and confirm exits with unsaved changes.
  • Add recurring schedules and an editable daily agenda.
  • Support negotiated CLI shortcuts and image paste.

Bug Fixes

  • Handle SIGTERM and SIGINT gracefully instead of waiting on the quit confirmation dialog.
  • Recover the Task badge's behind count when background fetches keep failing.
  • Make the Task branch badge a sync action instead of a "?" marker.
  • Let slow fetches finish and make the sync button join in-flight fetches.
  • Isolate native file watchers and bound shutdown work.
  • Harden Cmd+Q shutdown under extreme load and improve Windows process snapshots and terminal teardown during quit.
  • Prevent subscription storms caused by working-directory flip-flops.
  • Use consistent physical-key mapping for shortcut recording and dispatch.
  • Harden Windows build entrypoints and prepare patched native modules in isolated paths.
