关键体验不变量

换配色清单，不换工作台。主题/语言切换不得重建 PTY、Terminal、Monaco model、Diff 内容或 Agent 任务；语言不更改子进程 LANG/LC_*。

Onward Light 起点：画布 #F5F7FA、正文 #17212F、操作蓝 #175CD3。这些是设计起点，实际以组件合成后的对比度验收为准。

一条受控数据流，服务所有表面

理由：当前 CSS、xterm、Monaco 与 Pierre 各有深色硬编码；若各组件自己决定主题，会出现“主界面白、History 黑”的分裂状态。解析后的不可变快照把同一有效明暗类别交给所有显示表面，同时把资源文件隔离在主进程。

需要你确认的策略边界

以下来自规格 D01–D08，且涉及持久化、同步与缓存范围。按仓库规则，未确认前只做审计与样稿，不写生产策略。

D01–D03：设置、启动、终端

新增 appearance v1；主进程为持久化和系统明暗权威；旧用户保持深色与原独立终端 palette，新用户仍默认深色。避免升级时突然改变工作习惯。

D04：预览缓存

保留内容缓存；仅让已烘焙颜色的预览产物失效；保活页在再次可见前应用最新主题。不清空全局缓存、不加 TTL/预热。

D05–D06：资源包与中文

离线、本地、声明式资源包；无 JS、无联网。普通 UI 切换即时，Monaco NLS 下次启动生效；资源包仅覆盖 Onward 文案。

D07–D08：测试与性能

英文主矩阵保留，新增 locale 专用覆盖；性能先真实测量。若未指定预算，按 MEASUREMENT_ONLY 交付测量与不变量，不虚报 SLA。

建议确认文本：“批准按文档 D01–D07 实施；D08 采用 MEASUREMENT_ONLY。” 若要对任一项改策略，我会先更新这份评审稿和验收清单。

验收口径：每一条都能被证据反驳

视觉与可访问性

所有表面使用同一有效明暗类别；普通文字 ≥ 4.5:1、必要控件 ≥ 3:1；导入主题不自动宣称无障碍，失败项必须列报告并由用户确认后启用。

状态保持

主题切换前后 manager session ID + main PTY identity/启动计数一致；Monaco model URI、dirty/undo/选区/滚动和 Git History 选择保留。

语言与插件安全

官方 en/zh-CN 的 missing/extra/placeholder/empty 均为零；资源包只读取已安装目录的白名单数据，非法路径、循环 include、恶意字段、坏包均可恢复。

结果状态

每项以 PASS / FAIL / BLOCKED / NOT_RUN / NOT_APPLICABLE 记录。构建或类型检查不替代功能验收；性能采用 D08 的测量记录或已批准阈值。
