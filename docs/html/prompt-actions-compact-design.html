这一版的操作方式How this version works

  • 点色块选中动作；左右拖动调整位置。选中后也可用 Alt+←/→ 移动。Click a block to select it; drag horizontally to reorder. Alt+Left/Right is the keyboard alternative.
  • 只编辑当前动作。隐藏的动作可从预览右侧下拉框找到；隐藏后仍可试用快捷键。Edit one action at a time. The dropdown also lists hidden actions, whose shortcuts remain testable.
  • 颜色、名称、顺序同步到上方发送区样例。鼠标悬停色块可看名称与按键。Colors, names and order update the sender mockup above. Hover blocks for names and keys.
  • 点试键区域后输入 Leader → 动作键，或 Leader → 数字 → 动作键。命中动作时对应色块亮起。Focus the test area, then press Leader → action, or Leader → number → action. The matching block lights up.
  • 按钮较多时保持同一排和最小点击宽度，横向滚动，不挤成多排。Many buttons stay on one row with a minimum hit width and horizontal scrolling.

线程边界：小型表单、颜色与拖动属于 renderer 的 DOM/输入工作；颜色校验与排序为有界纯函数，保存仍通过已有 main IPC。拖动只在结束时记录变更，避免 pointermove 逐帧写日志或持久化。Thread boundary: the small form, colors and dragging are renderer DOM/input work; validation and ordering are bounded pure functions. Persistence uses existing main IPC. Drag changes are recorded on completion, not persisted or traced per pointer move.

同类产品的依据Peer-product evidence

借鉴的是紧凑布局、按需披露、即时预览及键盘识别反馈。等宽色块、每动作自定义颜色与本地试键区是针对本次需求的组合设计。The precedents support compact layout, progressive disclosure, live preview and key recognition feedback. Equal-width color blocks, per-action colors and a local test area are a tailored combination.

  • JetBrains · New UI — 紧凑模式缩小高度/间距，名称可在悬停时显示，复杂功能按需展开。 — Compact Mode reduces heights/spacing; names can appear on hover; complex features are progressively disclosed.
  • JetBrains · Menus and toolbars — 独立的动作增删、顺序与图标配置；文档中的自定义颜色用于项目头部。 — Dedicated action/order/icon editing; documented custom colors apply to project headers.
  • VS Code · Themes — 选择器内即时预览，确认后选择。 — Immediate preview within the picker, followed by selection.
  • VS Code · Keyboard shortcuts — 按键定义、冲突查看、实际命令调用诊断是不同的交互。 — Key capture, conflict inspection and live command troubleshooting are distinct interactions.
